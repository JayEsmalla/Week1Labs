# Week1Labs - StudyBuddy

A student task and reminder app built with React Native, Expo, and Firebase as part of a three-week mobile app development course.

## Features

- Email and password login and sign up
- Add, complete, and delete tasks
- Live cloud synchronization with Firebase Firestore
- Private task lists scoped to each signed-in user
- Motivational quotes loaded from a web API

## Built With

- React Native
- Expo
- Firebase Authentication
- Firebase Firestore
- React Navigation

## Run Locally

1. Install dependencies with `npm install`.
2. Start Expo with `npx expo start`.
3. Open the project in Expo Go or an Android emulator.
